Capture Kit / Figma development plugin

Import editable native layers

Choose the Figma Native JSON downloaded by the Capture Kit extension.

Accepts one Capture or an array of Captures. Images must be embedded in the capture; this plugin makes no network requests.
Select a .capture.json file to begin.
Import diagnostics
    What stays editable?

    Frames, text, bitmap image fills, colors, borders and SVG paths become native Figma layers. Supported horizontal and vertical flex containers become real Auto Layout frames with fixed captured dimensions and cross-axis fill for stretch.

    Grid, wrapped flex, transforms and complex CSS use captured positioned bounds instead. Flex whose captured child bounds disagree with its layout metadata also stays positioned. Warnings identify omitted or approximate effects, asset failures and actual font substitutions.

    Available Figma fonts are loaded before text is created. Embedded web fonts cannot be installed automatically. Figma text shaping and line wrapping can differ from the browser.

    SVG clipboard is a separate export. Pasting the extension's Figma SVG clipboard format does not create native Auto Layout. This plugin imports Capture JSON, not clipboard SVG or HTML.

    Development installation

    From the repository, install dependencies and run pnpm --filter @capture-kit/figma-plugin build after building its workspace dependencies. In Figma, use Plugins / Development / Import plugin from manifest and select apps/figma-plugin/dist/manifest.json.

    The build emits self-contained code.js, ui.html and manifest.json. No Figma access token or server is required. Real native rendering still needs verification inside a Figma design file.
